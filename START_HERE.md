# HOW TO WORK

# EVERY TASK MUST FOLLOW THIS FLOW

---

# STEP 1 — ANALYZE

Перед кодом:
- изучи текущую реализацию
- изучи architecture
- изучи UX flow
- изучи dependencies
- изучи existing systems

---

# STEP 2 — IDENTIFY PROBLEMS

Определи:
- UX problems
- visual problems
- responsive issues
- performance bottlenecks
- architecture risks

---

# STEP 3 — CREATE STRATEGY

Перед кодом:
- объясни current state
- объясни problems
- объясни implementation strategy
- объясни expected result

---

# STEP 4 — IMPLEMENT SAFELY

Изменения обязаны быть:
- modular
- scalable
- readable
- reversible
- production-safe

---

# NEVER

- giant rewrites
- architecture chaos
- overengineering
- random abstractions
- unnecessary complexity

---

# STEP 5 — QA VALIDATION

После изменений обязательно проверить:

## FUNCTIONAL QA

- logic works?
- cart stable?
- localization works?
- checkout works?
- no runtime errors?

---

## UI QA

- spacing consistent?
- hierarchy readable?
- responsive stable?
- visual calmness preserved?

---

## UX QA

- flow intuitive?
- no unnecessary friction?
- interactions smooth?
- mobile UX comfortable?

---

## PERFORMANCE QA

- rendering optimized?
- animations smooth?
- no layout shifts?
- hydration safe?

---

# STEP 6 — FINAL POLISH

После working implementation:
- улучшить spacing
