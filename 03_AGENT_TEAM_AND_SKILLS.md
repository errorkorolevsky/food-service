- анализирует проект со своей стороны
- предотвращает ошибки

- усиливает product quality
- сохраняет consistency

Claude Code обязан:
- комбинировать мышление всех агентов
- избегать конфликтующих решений
- сохранять баланс между:
  - UX
  - business
  - visual quality
  - performance
  - scalability
