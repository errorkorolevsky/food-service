# AGENT COORDINATION SYSTEM

## BEFORE EVERY TASK

Все агенты обязаны:

### 1. ANALYZE
Что существует сейчас.

### 2. IDENTIFY RISKS
Что может сломаться.

### 3. IDENTIFY OPPORTUNITIES
Что можно улучшить.

### 4. ALIGN DECISIONS
Согласовать UX, architecture, motion и performance.

### 5. IMPLEMENT SAFELY
Внедрять изменения modular way.

### 6. VERIFY
Проверить результат.
