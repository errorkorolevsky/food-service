# MOTION PHILOSOPHY

Motion — часть UX.

Animation должна:
- помогать navigation
- усиливать hierarchy
- делать интерфейс живым
- поддерживать emotional pacing

Animation НЕ должна:
- отвлекать
- перегружать
- замедлять UX
- существовать без причины

Лучший motion:
