# Image Acquisition Plan — Реальные фото продуктов
**Date:** 2026-05-29  
**Status:** Active — заменяет подход с генерацией через Pollinations/DALL-E

---

## Почему отклонена AI-генерация

Сгенерированные через Pollinations AI (Flux) изображения:
- Cartoon/icon-like, не реалистичные фото продуктов
- Не похожи на реальную супермаркет-фотографию
- Визуально несовместимы с уровнем Magnum / Arbuz.kz
- Не основаны на реальном ассортименте

**Единственный приемлемый стандарт:** `lays-chips.webp` — реальное фото продукта Lay's.

---

## Цель

Изображения должны выглядеть как **реальные фото товаров из супермаркета**:
- Реальная потребительская упаковка
- Профессиональная студийная съёмка
- Единый стиль: тёмный фон, чистый кроп
- Референс: Magnum KZ, Kaspi Магазин, Arbuz.kz

---

## Новый пайплайн (4 фазы)

### PHASE 1 — Source Audit
Задача: найти источник реального ассортимента и фотографий.

**Кандидаты для скрапинга/экспорта:**
- `magnum.kz` — онлайн-супермаркет, Казахстан (основной референс)
- `kaspi.kz/magnum` — Kaspi Магазин раздел продуктов
- `arbuz.kz` — онлайн-магазин продуктов, KZ
- `small.kz` — ещё один KZ ритейлер

**Что нужно из источника:**
- Название продукта (RU + KZ если есть)
- Категория / подкатегория
- Цена, единица измерения
- URL изображения продукта

**Формат выходного файла:** `docs/catalog-audit/source-products.json`
```json
[
  {
    "source": "magnum",
    "source_id": "12345",
    "title": "Яйца куриные С1 10шт",
    "category": "Яйца",
    "price": 890,
    "unit": "10шт",
    "image_url": "https://...",
    "our_product_id": "eggs-c1"
  }
]
```

---

### PHASE 2 — Image Collection

Для каждого продукта из source-products.json:
1. Скачать оригинальное изображение из источника
2. Сохранить в `public/products/source-raw/<product-id>-source.jpg`
3. Зафиксировать соответствие в `docs/catalog-audit/image-mapping.json`

**Правила:**
- Использовать как референс, не копировать UI источника
- Если у источника нет изображения — пометить `"needs_image": true`
- Не генерировать placeholder если нет реального источника

---

### PHASE 3 — Image Processing

Обработка каждого скачанного изображения:
- Кроп: только продукт, без UI источника
- Фон: тёмный #0A0A0A или нейтральный (Photoshop / sharp remove-bg)
- Размер: 600×800px WebP, quality 88
- Без логотипов Magnum/Kaspi в кадре
- Сохранить в `public/products/<product-id>.webp`

**Инструменты:**
- `sharp` (уже установлен) — ресайз, конвертация
- `@imgly/background-removal` — удаление фона (node.js)
- Ручная доработка если нужно

---

### PHASE 4 — Product Mapping

Только после одобрения 5–10 продуктов из пробного батча:
1. Добавить `image: "/products/<id>.webp"` в `products.ts`
2. Пересеять Supabase: `npx tsx scripts/seed-products.ts`
3. Проверить в браузере на `/catalog`

## Критерии одобрения изображения

Перед добавлением в каталог каждое изображение должно пройти:

- [ ] Реальная потребительская упаковка (не оптовая, не самодельная)
- [ ] Правильный размер/вес (200г масло ≠ 1кг блок)
- [ ] Тёмный или нейтральный фон
- [ ] Нет UI-элементов источника (кнопки, цены, логотип магазина)
- [ ] Нет логотипа "FOOD SERVICE KAZAKHSTAN"
- [ ] Продукт занимает 60–75% кадра
- [ ] Разрешение достаточное (минимум 400px по меньшей стороне)
- [ ] Цвет натуральный (красные томаты, оранжевый лосось)
