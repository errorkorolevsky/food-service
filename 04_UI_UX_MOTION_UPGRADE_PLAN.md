# MOTION SYSTEM

# MOTION PRINCIPLE

Motion существует:
- для UX
- для hierarchy
- для feedback
- для emotional pacing

НЕ:
- для демонстрации motion skills
- для flashy experience
- для постоянного wow-effect

---

# MOTION MUST FEEL

- subtle
- intelligent
- lightweight
- responsive
- cinematic
- calm

---

# MOTION RESTRAINT SYSTEM

Лучший motion:
почти незаметен,
но делает интерфейс:
- smoother
- clearer
- more tactile
- more premium

---

# ALLOWED MOTION

Разрешено:
- soft fade
- opacity reveal
- subtle hover feedback
- gentle transforms
- smooth transitions
- lightweight parallax
- tactile button response

---

# FORBIDDEN MOTION

Запрещено:
- bounce overload
- dramatic scaling
- constant movement
- distracting parallax
- flashy reveals
- motion spam
- exaggerated transforms

---

# MOTION TIMING SYSTEM

### FAST
150ms–250ms

Использовать:
- hover
- button feedback

### MEDIUM
300ms–500ms

Использовать:
- reveals
- drawer transitions
- section transitions

### SLOW
600ms–900ms

Использовать:
- atmospheric transitions
- cinematic depth

---

# PERFORMANCE-FIRST MOTION

Motion НЕ должен:
- лагать
- нагружать rendering
- снижать FPS
- ломать UX

Использовать:
- GPU-friendly transforms
- opacity
- optimized animation logic
