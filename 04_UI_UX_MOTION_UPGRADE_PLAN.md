# MOTION TIMING RULES

## STANDARD ANIMATION SPEED

### FAST
150ms–250ms

Для:
- hover
- small interactions

### MEDIUM
300ms–500ms

Для:
- reveals
- transitions

### SLOW
600ms–1200ms

Для:
- cinematic sections
- ambient motion

## EASING

Использовать:
- ease-out
- spring
- smooth bezier curves

Избегать:
- linear robotic feeling


---

# PERFORMANCE RULES

Все анимации обязаны:
- быть GPU-friendly
- использовать transform/opacity
- избегать layout thrashing

## NEVER:
- animate width/height excessively
- create FPS drops
- overload DOM

## ALWAYS:
- optimize motion
- lazy load heavy visuals
- reduce unnecessary effects
